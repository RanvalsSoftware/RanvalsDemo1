SECURE BY DESIGN

Trust every delivery before processing it

  • GET callback challenge with a per-connection verify token
  • Mandatory X-Hub-Signature-256 HMAC verification
  • Exact raw-body validation and constant-time comparison
  • 1 MiB request limit and strict Page/leadgen filtering
  • Bearer token plus App Secret Proof on Graph requests
  • Known credentials redacted from recorded errors

Requirements and honest expectations

  • Designed for Odoo.sh and on-premise deployments that allow custom Python modules; not Odoo Online/SaaS.
  • Requires Odoo CRM plus the standard UTM and Mail modules.
  • Requires a Meta Developer app, a Facebook Page, an Instant Form, a Page Access Token and the applicable Meta permissions.
  • Typically requires leads_retrieval, pages_manage_metadata, Page Lead Access, and token-flow permissions such as pages_show_list. Meta App Review/Business Verification may apply.
  • Optional campaign/ad names can depend on additional Meta advertising access; the module falls back to core lead fields when possible.
  • Meta API versions and permission policies change. Validate v26.0 and your access model before production deployment.
